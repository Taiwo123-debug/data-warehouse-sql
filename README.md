# Data Warehouse and Analytics Project

## About
This project focuses on building a small data warehouse and using the stored data for exploratory and advanced data analysis.

The project involves importing raw data from CSV files, including customer, product, and sales data, then cleaning and transforming the data to make it suitable for business use and analysis.

The data is processed using the Medallion Architecture, with three layers: **Bronze, Silver, and Gold**. The Bronze layer stores the raw data, the Silver layer contains cleaned and transformed data, and the Gold layer contains business-ready data prepared for reporting and analysis.

The data warehouse is built using **Microsoft SQL Server**, while **Draw.io** is used to design and document the data warehouse architecture.

The project also includes loading CSV data into SQL Server using SQL operations such as TRUNCATE and INSERT, followed by exploratory data analysis and advanced data analysis to extract useful business insights.

## Initial Requirements
* Raw CSV datasets containing customer, product,sales and other related information
* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* Draw.io for architecture and data flow diagrams
* SQL for data loading, cleaning, transformation, and analysis
* A GitHub repository for documenting and managing the project

  ## Objectives
* Build a structured data warehouse using Microsoft SQL Server.
* Implement the Bronze, Silver, and Gold layers of the Medallion Architecture.
* Import raw data from CSV files into the data warehouse.
* Clean and transform raw data into reliable, consistent datasets.
* Create business-ready data for analysis and reporting.
* Perform exploratory data analysis to understand the data and identify patterns.
* Perform advanced data analysis to generate useful business insights.
